## 🚀 Deployment Options

### Opción 1: Local Development
```powershell
pip install -r requirements.txt
streamlit run app/streamlit_app.py
```
**Tiempo**: 2 minutos  
**Uso**: Desarrollo local

### Opción 2: Docker Local
```powershell
docker-compose up -d
```
**Tiempo**: 5 minutos (primera vez)  
**Uso**: Testing, staging

### Opción 3: Docker con IA
```powershell
docker-compose --profile with-ai up -d
```
**Tiempo**: 10 minutos (primera vez, incluye descarga modelo)  
**Uso**: Full stack local

### Opción 4: Cloud Deploy (Futuro)
```powershell
# Azure Container Instances
az container create --resource-group rg-carbon --name carbon-ghg --image carbon-ghg:1.0

# AWS ECS
aws ecs create-service --cluster carbon-cluster --service-name carbon-ghg

# Google Cloud Run
gcloud run deploy carbon-ghg --image gcr.io/project/carbon-ghg
```
